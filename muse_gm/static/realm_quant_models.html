Important: These are audio-codec models, not chatbot language encoders or text tokenizers. The MUSE-GM app currently provides downloads and research context only; it does not run ONNX inference or process audio.

Performance caveat

The Realm of Quant report measured single-thread WASM on a 2-vCPU server and reported RTF 1.43 for the encoder and 3.16 for the decoder. Both were slower than realtime in that test. WebGPU and mobile performance were not measured. Both model files together are about 151.5 MB on the wire, with substantially higher reported browser memory use.
